# PSXctr

Work-in-progress PlayStation emulator for the New Nintendo 3DS, built on the
PCSX-ReARMed emulation core.

## Status

Early development. Nothing runnable yet.

## Legal

No games or BIOS files are included or will be distributed. You must supply
your own legally obtained copies.
